## List of Exercises

**Creating the Project** ([exercise 0](exercise0)) - Just README.md about starting and configure for current project. 

**Perimeter of a Triangle** ([exercise 1](exercise1)) - Reads 6 coordinates, checks if they form a triangle, calculates perimeter.

**Hours, Minutes, Seconds** ([exercise 2](exercise2)) - Converts total seconds into `hh:mm:ss` format

**Fibonacci Number** ([exercise 3](exercise3)) - Finds n-th Fibonacci number recursively.

**Arithmetic Mean of Negative Numbers** ([exercise 4](exercise4)) - Reads integers into an array, averages only negatives. 

**Numbers with Same First and Last Digits** ([exercise 5](exercise5)) - Filters numbers whose first and last digits match.

**Selection Sort of Array** ([exercise 6](exercise6)) - Sorts floating-point numbers in ascending order.

**Min and Max from File**  ([exercise 7](exercise7)) - Reads numbers from a file, handles errors, saves min/max to `result.txt`.

**Ascending Order Sequence** ([exercise 8](exercise8)) - Checks if a sequence is strictly increasing without arrays.

**String Filtering** ([exercise 9](exercise9)) - Filters strings containing a given substring.

**Names of Adult Users** ([exercise 10](exercise10)) - Filters users by age (≥18) using Stream API.
